# Craftmax menu assets

These images are the initial game branding used by Luanti's game selector:

- `background.png` is the menu background.
- `header.png` is the menu header image.
- `icon.png` is the Craftmax game icon.

The images come from the CC0 Kenney Voxel Pack stored under `textures/` and can
be replaced with final Craftmax artwork later.
