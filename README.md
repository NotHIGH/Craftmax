# Craftmax

Craftmax is an open-source, single-player endless survival game for Minetest/Luanti.

## Current prototype

- Procedurally generated plains biome
- Grass, dirt, stone, sand, wood, leaves, coal ore, and campfires
- Apple food item and hunger system
- Stone pickaxe and basic crafting recipes
- No fixed ending: explore and survive as long as possible

## Run locally

1. Install Minetest or Luanti.
2. Clone this repository into the game's `games` directory, or point the launcher at this folder as a game.
3. Create a new world with the `Craftmax` game selected.
4. Enable damage and start playing.

The project is currently a playable foundation. The next planned slice is procedural trees, hostile night creatures, and a saveable day/night survival loop.
